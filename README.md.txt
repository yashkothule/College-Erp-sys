# College ERP System

A full-stack College Enterprise Resource Planning (ERP) system designed to manage academic and administrative activities through a centralized web application.

## Features

- Student management
- Faculty management
- Course and department management
- Attendance management
- Academic records management
- Fee management
- Admin dashboard
- REST API backend
- MySQL database
- PDF generation
- Web-based user interface

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL 8

### Other Technologies
- REST APIs
- PDF generation
- Git & GitHub
